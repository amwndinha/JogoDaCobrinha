# Jogo da Cobrinha

Um jogo clássico da Cobrinha (Snake) desenvolvido em Python, com o objetivo de praticar lógica de programação, estruturas de repetição, condicionais e interação com o teclado.

## Sobre o projeto

Neste jogo, o jogador controla uma cobra que deve comer a comida que aparece na tela. A cada comida coletada, a cobra aumenta de tamanho e a pontuação é incrementada. O jogo termina quando a cobra colide com as bordas da tela ou com o próprio corpo.

## Tecnologias utilizadas

- Python
- Pygame

## Objetivo do projeto

Este projeto foi desenvolvido como forma de praticar programação em Python, colocando em prática conceitos como:

Variáveis
Condicionais
Laços de repetição
Funções
Listas
Eventos do teclado
Colisões
Pontuação
Biblioteca Pygame
